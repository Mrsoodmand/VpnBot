# چیدمان منوها و عنوان پیام‌های ربات

تاریخ: ۲۰۲۶-۱۰-۲۶

این بسته ادامهٔ نسخهٔ بازطراحی مدیریت VIP است و هر دو درخواست اخیر را دارد:

- کشورها برای کاربر دو دکمه در هر ردیف نمایش داده می‌شوند. آلمان قبل از صفحه‌بندی در اولویت اول قرار می‌گیرد؛ تشخیص بر اساس نام فارسی/انگلیسی/آلمانی یا پرچم است.
- «همه کشورها» تک‌دکمه و تمام‌عرض باقی می‌ماند.
- دکمه‌های کوتاه و متوالی در منوهای ادمین و کاربر کنار هم قرار می‌گیرند. متن‌های بلند، برگشت/انصراف، عنوان دسته‌ها و چیدمان‌های چنددکمه‌ای موجود حفظ می‌شوند. متن و عملکرد دکمه‌ها عوض نشده‌اند.
- عنوان هر صفحه با خط جداکننده زیر آن نمایش داده می‌شود. عنوان‌ها متناسب با مرحله‌اند، مانند انتخاب کشور، انتخاب تعرفه، پیش‌فاکتور خرید، پیش‌فاکتور تمدید، پیش‌فاکتور حجم اضافه، ارسال رسید، وضعیت پرداخت، مدیریت کشور و ویرایش تنظیمات.
- فاصلهٔ خالی پس از عنوان‌های قبلی حذف شده و متن فارسی پیش‌فاکتور خرید با فونت عادی نمایش داده می‌شود. اطلاعات قابل کپی مانند شماره کارت و کد کانفیگ همچنان قالب مناسب خود را دارند.

نمونه:

```text
🧾 پیش‌فاکتور خرید
────────────────────────────────
کشور: همه کشورها
تعرفه: ۲۰ گیگ ۳۰ روز
مبلغ کل: ۱۷۰٬۰۰۰ تومان
```

## نصب

بستهٔ `bot-menu-layout-and-headers-2026-10-26.zip` شامل ۱۵ فایل اجرایی کامل، راهنما و نتیجهٔ تست‌هاست. فایل‌های اصلاحات قبلی مدیریت، قیمت و تحویل هم در آن هستند؛ نصب بستهٔ قبلی بعد از این بسته لازم نیست.

تمام فایل‌های `app/` بسته را با حفظ مسیر در ریشهٔ پروژهٔ Laravel ربات جایگزین کنید؛ فایل جدید `app/Services/BotKeyboardLayout.php` حتماً منتقل شود. سپس:

```sh
composer dump-autoload --no-dev --optimize
php artisan optimize:clear
php artisan queue:restart
```

اگر OPcache سرور تغییر زمان فایل‌ها را بررسی نمی‌کند، PHP با روش معمول هاست reload شود. سپس `/start` بزنید و منو را دوباره باز کنید؛ پیام‌های قدیمی خودبه‌خود ویرایش نمی‌شوند.

migration، تغییر دیتابیس یا `.env` لازم نیست. تنظیمات و فایل‌های محرمانه داخل بسته نیستند. بستهٔ قبلی و بکاپ اصلی دست‌نخورده باقی مانده‌اند. تغییرات هنوز روی سرور نصب نشده‌اند.

## بررسی

۱۳۸ تست و ۱۱۰۱ assertion موفق؛ بررسی syntax فایل‌های بسته و `git diff --check` موفق. خروجی واقعی سازندهٔ منو با دادهٔ نمونه برای هشت کشور، تنظیمات، ویرایش پنل و پیش‌فاکتور خرید بررسی شد: آلمان اولین گزینه است؛ کشورها چهار ردیف دوتایی دارند؛ همه کشورها و برگشت هر کدام یک ردیف مستقل دارند. این بررسی محلی با SQLite موقت و بدون ارسال پیام یا پرداخت واقعی انجام شد.
